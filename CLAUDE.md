## Правила кода (уроки HORIN)

- `prefers-reduced-motion` игнорируется сознательно (Windows-кейс) — не возвращать.
- DOM-стили писать только при реальном изменении значения (не каждый кадр).
- JS не пишет transform элементам, чей transform управляется media query.
- **Enter в редакторе:** в полях без `data-edit-type="html"` Enter завершает правку (blur) — если тексту нужен перенос строки, поле обязано быть html-типа. В html-полях Enter вставляет `<br>` (`insertLineBreak`), а не браузерный `<div>` — иначе в CMS попадают лишние блоки и едут отступы.
- Классы шторки перехода — `w-in`/`w-out` (не `in`/`out` — конфликт с entrance-анимацией контента на kontakt).
- После правок прогонять puppeteer-проверку: 1440×900 + 390×844, 0 console errors, 0 переполнений. Скрипты в `/tmp/pptr-fiq/` (puppeteer-core + Chrome из `~/.cache/puppeteer`). **Не использовать `clip` + `deviceScaleFactor: 2`** — отдаёт чёрные клипы; делать полные скриншоты. `page.waitForFunction` в headless задавать `{ polling: 300 }` — дефолтный rAF в фоновой вкладке не тикает и ожидание виснет до таймаута. Детектор переполнений обязан пропускать элементы неактивных граней барабана: 3D-проекция искажает их `getBoundingClientRect`, а `#stage` их и так обрезает.

- **Реестр продуктов платформы `fiq_products` (2026-09-08):** зонтик `brain` = «Agenci AI» разделён на два продукта — **`advisor`** («AI Doradca») и **`sales`** («AI Sprzedawca»), оба в домене `brain.fastlineinfinitiq.pl` (AI Asystent добавим, когда будет модуль). Панель фильтрует меню/роуты/вкладки/интеграции по `session.product.key`, админ видит всё; ключи домена — в `Prod/brain.fastlineinfinitiq/src/lib/products.js`. Проекты привязываются к продуктам таблицей **`fiq_project_products`** (пусто = проект во всех продуктах воркспейса), управление — Admin → Workspace'y → «Projekty i ich produkty». Правила платформы — вики `platform-multi-product`, общий слой — `Prod/fiq-shared` (после правок обязателен `npm run sync:shared` в каждом продукте).
